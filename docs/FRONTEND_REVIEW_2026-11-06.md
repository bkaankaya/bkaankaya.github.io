## Design changes

- Identity and media are now separate data fields and components. The original QuickScan and Vague logos appear only in the small project badges.
- QuickScan's real 720 × 1600 mobile sign-in capture is displayed in a proportionate device viewport instead of a large cropped login or a large logo.
- The archive uses two spacious desktop columns and a single mobile column. The final game project uses a full-width split layout on wide screens.
- Restrained type hierarchy, spacing, borders, metadata, tags, hero and footer refinements preserve the existing violet/navy identity and navigation interactions.
- Native project dialogs explicitly restore centered margins, have bounded scrollable height, sticky close controls, Escape dismissal and focus restoration.
- ReZero has delayed 5-second hover crossfades, intent-based preloading and manual modal controls for keyboard/touch users. Reduced motion, coarse pointers, Save-Data and hidden tabs do not run automatic rotation. Undecoded/failed frames are not selected by the timer.
