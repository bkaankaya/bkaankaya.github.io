01 / CONTEXT

The challenge

Different movie attributes carry very different signals. A meaningful similarity engine has to represent those modalities without letting one dominate the others.

02 / ENGINEERING

The approach

In a three-person university team, explored autoencoder, contrastive and deep-clustering approaches over a documented 329,044-row, 564-feature matrix. The project used clustering and retrieval evaluations, then connected a selected embedding model to a recommendation demo.

03 / NOTES

Key details

  • 329,044 movie records and 564 input features in the documented feature matrix.
  • The project progress log reports genre@5 = 0.723 for the selected ae_z32 model.
  • Negative experiments and architecture tradeoffs were documented as part of the process.

Scope & verification

Team project. Published measurements describe the project as a whole, not a claim that any one contributor produced every result.
