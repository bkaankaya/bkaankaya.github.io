01 / CONTEXT

The challenge

Reading exam pages is only one part of an education workflow: privacy, identity handling, reviewability and correct state transitions matter just as much.

02 / ENGINEERING

The approach

The documented stack connects a Spring Boot backend, FastAPI visual extraction and Flutter experiences. It uses asynchronous processing, schema-checked results and teacher review flows, with local identity protection before external model calls.

03 / NOTES

Key details

  • Structured visual extraction with multimodal LLMs.
  • Teacher, student and parent application flows.
  • Explicit review states and privacy-minded processing controls.

Scope & verification

Private repository. No student data, unpublished test sets or private source code are exposed.
