01 / CONTEXT

The challenge

Serial sensor monitoring requires framing, validation and correct decoding between firmware and operator-facing software.

02 / ENGINEERING

The approach

Developed firmware reading internal temperature and reference-voltage channels, and a Qt application requesting Modbus RTU-style holding registers through UART. Tests cover frame parsing and CRC checks.

03 / NOTES

Key details

  • Function 0x03 register access and CRC16 validation.
  • Qt desktop UI for readings and button state.
  • Repository documents CI builds and protocol tests.

Scope & verification

Engineering learning system, not certified industrial Modbus equipment; hardware validation remains distinct from software tests.
